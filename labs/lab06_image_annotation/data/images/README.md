# Image pool for Lab 6

This folder is where the unlabelled wildlife photo pool goes before you start
annotating. It isn't bundled in this repository or the Docker image (size and
licensing) — your instructor provides it separately.

## What goes here

Drop the raw `.jpg` photos flat into this folder (`data/images/*.jpg` — no
subfolders). Nothing else needs to change: `lab06.ipynb` reads this folder
directly, and `classes.txt` / `data.yaml` alongside it already define the
class list the annotator and later labs expect.

Once the pool is in place, start at Section 2 of `lab06.ipynb`.

(`images/train/`, `images/val/`, `images/test/` are generated by the
notebook itself in Section 5 — don't create those by hand.)
